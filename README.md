# 🌶️ AnjaraiPetti – Homemade Spices Shop App UI/UX Design

## 📌 Overview
AnjaraiPetti is a mobile app UI/UX design concept for an e-commerce platform that delivers homemade, preservative-free spices. The design focuses on simplicity, usability, and a culturally rich user experience.

---

## 🎯 Objective
- Create a clean and intuitive shopping experience  
- Promote traditional homemade spice products  
- Ensure smooth navigation and checkout flow  

---

## ✨ Features
- 🏠 Home Screen with offers & highlights  
- 🛍️ Product Listing with price, rating & deals  
- 🧾 Cart & Checkout flow  
- 🔐 OTP-based Login system  
- 📦 Category browsing (Masalas, Pickles, Fryums, etc.)  
- 💬 WhatsApp support integration  

---

## 🎨 Design Highlights
- Warm color palette inspired by spices  
- Simple and readable typography  
- Clear call-to-action buttons  
- Consistent layout and spacing  
- Bilingual support (English + Tamil)
